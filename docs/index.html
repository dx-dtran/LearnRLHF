LearnRLHF / visual guides repo

InstructGPT RLHF, visually

The conceptual layer of the course. Read these on your phone before a work session; the derivations and code live in notes/ and the repo.

The goal of the whole project is one sentence: take a pretrained GPT-2 that merely continues text, and turn it into a model that answers — using human preference data and three training phases. Each phase produces the starting point for the next.

1One dataset, three views

Everything trains on Anthropic HH-RLHF: pairs of multi-turn dialogues where a human marked one assistant reply chosen and one rejected. The same corpus gets sliced three ways, one per phase:

Derived datasetShapeFeeds
SFTfull chosen dialogue + loss masksupervised finetuning
Preference pairs(prompt, chosen, rejected)reward model
Prompt-onlyprompt, truncated ≤ 512 tokensPPO rollouts

Notice what is absent: PPO never sees the human-written responses. By phase three, the only supervision left is a single scalar from the reward model. That is the whole trick of RLHF — and the source of every failure mode in Module 5.

Four models on one GPU, the rollout–optimize rhythm, and how to read the training dashboard before it lies to you.

3How to use these

Each guide maps to the module you are about to start. Read it away from the keyboard — the widgets are meant to build the picture you will later formalize on paper. When a guide says derive this in notes/, that is the boundary: intuition here, math there, code in the repo. Nothing here writes the code for you.
